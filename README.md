这是一个跑在本机的网页应用：它把 `steamapps\workshop\content\431960` 下面的壁纸文件，以及 Wallpaper Engine 的 `projects\myprojects`，读成一面可以直接看、直接播的画廊。当你想欣赏已订阅到本地的视频壁纸时，想跳转、拖动进度条，必须右键壁纸一层一层点进文件夹中的文件才能做到；如果你跳到中间看了几秒，发现这个影视不合你的胃口，还要再一层层关掉之后再一层层打开新的文件，过于麻烦，而这个播放器很好的解决了这一痛点。这里可以按下载时间和大小排序、支持按标题搜索、点开就播，全程单手即可操作，方便你管理以及欣赏通过 Wallpaper Engine 订阅下载到本地的影视作品。它不安装服务、不写入系统级注册表，`package.json` 里没有任何依赖；内置版安装包自带 `node.exe`，下载 Setup 后按向导安装即可，服务只监听 `127.0.0.1`。

## 主要功能

### 播放

点击视频卡片，视频就在卡片内原地播放，不用离开画廊；卡片内播放器的全屏按钮会打开独立播放页，在播放页再点全屏就是浏览器真全屏。图片卡片点击后进入播放页看大图。鼠标在视频卡片上悬停会静音预览画面，移开即停。

双击视频卡片可以直接打开独立播放页并请求全屏；全屏状态下再次双击回到主页。右键卡片进入详情页，在详情页再次右键退出。详情页双击视频同样进入/退出全屏，退出全屏后回到详情页。


卡片内播放器和播放页都提供 **0.5× / 0.75× / 1× / 1.25× / 1.5× / 2× / 3× / 5×** 倍速选择。长按 `→` 会临时以 3 倍速播放，松开恢复原倍速；短按仍是前进 5 秒。

播放页提供进度条、音量、静音和全屏。**循环播放**是顶栏的开关，对所有视频生效。视频快捷键：`Space` 播放/暂停，`M` 静音，`F` 全屏，`←` 后退 5 秒，`→` 短按前进 5 秒 / 长按临时 3 倍速，`↑` / `↓` 音量加减 5。

高码率 4K 视频仍可能受浏览器解码能力影响而等待数秒；检测到较长时间的缓冲或解码等待时，页面会提示可以改用本地播放器。

场景（`scene.pkg`）、网页（`.html`）、应用（`.exe`）三类壁纸无法在浏览器里渲染，只显示卡片与说明，需要回到 Wallpaper Engine 运行。

### 删除

在卡片或播放页上直接删除，删除前有二次确认，并提示该壁纸在 Steam 的订阅记录仍然存在。删除只作用于本地文件，**不进回收站，无法撤销**；要让 Wallpaper Engine 不再下载，需要去创意工坊取消订阅。

### 移动与重命名

选中卡片后点「移动」，挑一个目标文件夹即可。移动时可以：

- 勾选「移动时重命名文件/文件夹」，用壁纸标题或原文件名作为新名字；
- 只移动壁纸的主文件，预览图、`project.json` 等留在原文件夹；
- 决定是否勾选「删除原文件/原文件夹」：
  - **不勾选**：复制到目标位置，原主文件、原文件夹及其中内容全部保留；
  - **勾选**：移动并删除原文件/原文件夹；
  - 只移动主文件且不勾选该项时，原主文件也会保留。

目标位置已有同名文件时，程序按大小相差 2% 以内或时长相差 1.5 秒以内判断是否为同一个文件：是同一个才让你选「删除源 / 覆盖 / 跳过」；判定不相似则自动改名，不会直接覆盖。同一批次里出现两个同名壁纸时，也可以进入对比页选择「自动重命名」，生成带序号的新名字。

在主页双击卡片标题可以重命名壁纸：会同时更新 `project.json` 中的标题与 `file` 路径，并重命名视频/图片主文件。目标文件已存在时会拒绝覆盖。

非视频/图片类型壁纸不支持「仅移动壁纸主文件」；勾选该项时，这类壁纸会按完整文件夹移动或复制。

### 多选

单击卡片右上角的选择按钮即可勾选。

在空白处按住鼠标拖动可以框选一片区域；拖动时按住 `Ctrl` 或 `Shift` 会在已有选择上追加。

批量操作栏提供全选与清空，选中后可以一次性移动或删除。

### 筛选

顶部标签按壁纸类型过滤：全部、视频、场景、网页、应用、其他。其中「其他」包含图片类壁纸。筛选与搜索、排序可以叠加使用。

顶部的 **NSFW** 开关控制是否显示被标记为 NSFW 的内容。默认隐藏，打开后才会显示；标记来自 `project.json` 的 `contentrating` 与标签。

### 搜索

工具栏的搜索框按标题实时过滤，不区分大小写，按 `Esc` 清空。只匹配标题，不检索文件夹名或文件内容。

### 排序与每行数量

排序下拉框支持：下载时间（新→旧 / 旧→新）、创建日期（新→旧 / 旧→新）、文件大小（大→小 / 小→大）、标题、文件夹 ID、文件名。每页可显示 10 / 20 / 30 / 50 / 100 张，底部分页栏支持输入页码直接跳转。

工具栏的「每行卡片数量」控制每行卡片数：

- `0` 为自动，默认值；
- 手动可填 1–30；
- 自动模式按视口宽高比计算：常见 16:9 / 21:9 全屏为 3 列，超宽矮屏为 4 列，竖屏为 1–2 列。

### 外观与提示

明暗主题切换使用平滑过渡；可以在顶栏快速切换，也可以在设置中跟随系统。

播放卡顿提示默认开启：检测到约 0.7 秒以上的缓冲或解码等待时，会建议使用 PotPlayer、VLC 等本地播放器。可以选择「本视频不再提示」「今日不再提示」，也可以在设置中彻底关闭。

## 配置需求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11。程序依赖注册表定位 Steam，并调用 `explorer.exe`、`rundll32.exe` 和 PowerShell |
| 运行环境 | Node.js 18 或更高版本。`Setup-Bundled` 安装包已内置 Node.js；`Setup-Lite` 需要系统已安装 Node.js |
| 浏览器 | 支持 HTML5 视频播放的现代浏览器。HEVC / H.265 能否播放取决于 Windows 与浏览器的解码能力 |
| 磁盘 | `Setup-Bundled` 约 25 MB，安装后约 92 MB（内含 `node.exe`）；`Setup-Lite` 约 3 MB |
| Wallpaper Engine | 不是必需项。没有安装时，可以在设置里手动选择任意本地壁纸文件夹 |

可选配置，全部可以跳过：

| 方式 | 用途 |
| --- | --- |
| 页面 **设置 → 浏览…** | 手动指定扫描根，优先级最高；选择结果记在程序目录的 `settings.json` |
| `server.mjs` 同目录的 `config.json` | 追加扫描根，格式为 `{ "roots": ["D:\\Wallpapers"] }`，**必须是不带 BOM 的 UTF-8** |
| 环境变量 `WALLPAPER_ENGINE_ROOTS` | 追加扫描根，多个目录用 `;` 分隔 |
| 环境变量 `PORT` | 起始端口，默认 `4319`，被占用时自动向后顺延 |

扫描只展开扫描根往下**一层**：根目录的直接子文件夹各算一张卡片；扫描根是自定义目录时，根目录里的图片和视频文件也各算一张卡片。

## 安装方式

### 方式一：下载安装包（推荐）

打开 [Releases](https://github.com/xdedmmc2/Wallpaper-Engine-player/releases/latest)，二选一：

- `Wallpaper-Engine-player-7.1.2-Setup-Bundled.exe`：内置 `node.exe`，不需要单独安装 Node.js。
- `Wallpaper-Engine-player-7.1.2-Setup-Lite.exe`：不内置 Node.js，需要系统里已有 Node.js 18 或更高版本。

运行安装程序后，可以选择安装位置。安装程序会在所选位置中自动创建名为 `Wallpaper Engine player` 的文件夹，并安装启动程序、卸载程序和运行所需的核心文件。

安装程序默认安装到当前用户的 `%LOCALAPPDATA%\Programs\Wallpaper Engine player`，不需要管理员权限；也可以改选其他可写目录。

安装目录中带有 `unins000.exe`，也可以在 Windows 的 **设置 → 应用** 中卸载。

首次运行如果弹出「Windows 已保护你的电脑」，点 **更多信息** → **仍要运行**。个人发布、未做代码签名时会这样提示，并非为有害文件。

启动后默认监听 `http://127.0.0.1:4319`。如果没自动找到壁纸库，点右上角 **设置** → **浏览…**，选中壁纸文件夹即可，选完立即生效。关闭最后一个页面后，页面会主动通知服务端，约 5 秒后服务自动退出；多标签页以最后一个页面为准，刷新页面不会误退出。

### 方式二：从源码运行

```bat
git clone https://github.com/xdedmmc2/Wallpaper-Engine-player.git
cd Wallpaper-Engine-player
npm start
```

不需要 `npm install`。`npm start` 会打开浏览器，并带上 `--auto-exit`；直接 `node server.mjs` 则不会自动退出。只想在终端里看地址、不自动开浏览器：

```bat
node server.mjs --no-open
```

## 常见场景

- **列表里少了壁纸**：确认它在扫描根往下**一层以内**，扩展名受支持（视频 `mp4 webm m4v mov mkv avi wmv flv ogv ts`，图片 `jpg jpeg png webp gif bmp avif`），且文件名不以 `preview.` 开头；如果只是被 NSFW 开关隐藏，打开顶部 NSFW 即可。
- **播放黑屏、只有声音**：视频编码浏览器解不了，典型是 HEVC / H.265 或 `.mkv` 容器。播放失败时页面给出「重试」和「系统播放」，后者交给本地播放器打开源文件。
- **4K 视频拖动或倍速后卡顿**：高码率 4K 视频受浏览器解码与关键帧定位限制，属于浏览器/硬件解码能力问题，不一定是磁盘或网络慢。页面会在等待超过约 0.7 秒时提示使用 PotPlayer、VLC 等本地播放器。
- **删了壁纸，Steam 里还显示订阅**：删除只作用于本地文件。要去创意工坊取消订阅，否则 Wallpaper Engine 下次同步可能重新下载。
- **移动后原文件夹没有删除**：检查「删除原文件/原文件夹」是否勾选；不勾选时是复制并保留原文件，这是有意行为。
- **关闭页面后命令行还在**：安装版从快捷方式启动，不显示命令行窗口；源码版双击 `启动.bat` 时，最后一个页面关闭后约 5 秒窗口会自动关闭。如果是在已打开的 PowerShell/CMD 里运行源码脚本，父终端不会被脚本关闭。
- **端口被占用**：程序从 `4319` 起顺延，最多试 20 个端口。已有实例在跑时，再次启动只会打开已有页面。
