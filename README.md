# Wallpaper-Engine-player

本地 Wallpaper Engine 壁纸画廊与播放器。零运行时依赖、无遥测、不包含任何壁纸内容。

## 功能

- 自动扫描 Steam 创意工坊 `431960` 与 `projects/myprojects`，也支持自定义目录。
- 四列自适应瀑布流，按视频/图片的真实比例排列。
- 按壁纸标题搜索；支持分类、日期、大小、标题等排序。
- 视频卡片悬停静音预览；卡片内直接播放。
- 播放流程：卡片内播放 → 右下角进入全屏播放页 → 播放页右下角进入浏览器真全屏。
- 播放页显示壁纸信息、简介和操作；退出全屏/返回时保持原位置。
- 卡片操作：删除 / 系统播放 / 目标文件夹 / 移动 / 选中。
- 拖动框选、批量移动/删除；操作前双重确认，并提示 Steam 订阅风险。
- 同名冲突时比较大小/时长：疑似同一文件可对比后删除源、覆盖或跳过；不相似自动改名。
- 移动完成可打开目标文件夹；资源管理器窗口自动置前。
- HEVC/H.265 依赖浏览器和 Windows 解码能力；实际播放失败才提示，可重试或交给系统播放器。
- 服务只监听 `127.0.0.1`，不上传壁纸、路径或使用数据。

## 启动

Windows 10/11，Node.js 18+。双击 `启动.bat`，或运行：

```bat
npm start
```

无需 `npm install`。默认使用 `4319` 端口，被占用时自动顺延。
